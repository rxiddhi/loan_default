# SmartCredit: Loan Default Analytics for Better Lending Decisions

Capstone project repository for loan default analytics in the finance/lending domain.

## Project Status
Phase 1 repository foundation initialized.

## Structure
- `data/raw/`: Original source files (not versioned except placeholders)
- `data/processed/`: Cleaned and modeled datasets
- `notebooks/`: Analysis notebooks
- `scripts/`: Utility/automation scripts
- `src/`: Reusable Python modules
- `tableau/screenshots/`: Dashboard screenshots for documentation
- `docs/`: Supporting documentation
- `reports/`: Final report and presentation assets
